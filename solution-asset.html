RFID 자산관리시스템

RFID Asset Management System

유형고정자산에 해당되는 재물(비품) 및 기자재, 전산장비, 의료장비 등을 RF리더기 · 태그 · 발행기와 같은 하드웨어와 자체 개발한 RFID 미들웨어를 결합하여 자산을 효율적으로 관리하는 시스템입니다. GS(Good Software) 인증을 획득한 제품으로, 공공기관 다수에 구축 · 운영되고 있습니다.

전자정부 표준프레임워크 기반으로 구축되며, 웹 자산관리시스템과 재물조사 APP을 통합 운영합니다. ERP 시스템과의 데이터 연계를 통해 자산의 취득 · 이동 · 불용 · 재물조사 전 과정을 표준화합니다.

주요 특징

  • 전자정부 표준프레임워크 기반 구축으로 공공기관 표준 준수
  • 웹 시스템 + 모바일 재물조사 APP 통합 운영
  • ERP · MIS · 전자결재 등 기존 시스템과의 양방향 데이터 연계
  • RFID 일괄 스캔으로 재물조사 소요시간 대폭 단축
  • 취득 · 이동 · 불용 · 반출입 전 과정 이력 실시간 추적
  • 오프라인 실사 지원 — 네트워크 없는 현장에서도 조사 가능
  • 자산 사용주기 분석을 통한 예산편성 효율화
  • 수작업 재물조사 대비 인력 · 비용 · 기간 절감

웹 · APP 데이터 동기화

실사 업무의 효율적 수행을 위해 웹 시스템과 앱 간 SQLite 기반 양방향 동기화 구조를 적용합니다. 비동기 파일 기반 구조로 네트워크가 불안정한 현장에서도 실사가 중단되지 않습니다.

목록 동기화

RFID 자산관리 서버 → 재물조사 APP
조사 대상 자산 목록을 SQLite 파일로 생성하여 태블릿에 내려받고, 앱의 로컬 DB에 저장합니다.

결과 동기화

재물조사 APP → RFID 자산관리 서버
RFID 스캔 결과를 실시간 기록한 뒤, 실사 완료 후 결과 파일을 서버로 업로드하여 DB에 반영합니다.

데이터 표준화

공공데이터 표준화 지침에 따라 자산코드 · 위치코드 · 부서 · 사용자 식별자를 표준화하고, UTF-8 · 날짜 · 코드 형식과 DB Schema · CodeSet · Domain 규격을 일원화합니다.

보안 · 품질관리

ERP 연계 시 API 인증과 전송 암호화(SSL)를 적용하고, DB 접근통제 · 계정 분리를 준수합니다. 실사 결과 무결성 검증과 중복 · 누락 검사 로그를 자동 생성합니다.

※ 데이터 연계 방식은 기관의 보안정책 또는 운영환경에 따라 조정 가능합니다.

사용자 중심 UI/UX

전 화면을 단일 프레임워크로 표준화하고, 실무자의 반복 조작을 시스템이 대신 기억 · 처리하며, 화면 곳곳에 상황별 안내를 내장하여 별도 매뉴얼 없이도 조작할 수 있도록 설계했습니다.

편의 기능

  • 화면 표준화 — 취득 · 이동 · 불용 · 대여 · 재물조사 전 업무를 단일 공통 화면구조로 표준화. 한 화면만 익히면 전 화면 조작 가능
  • 멀티탭 상태 유지 — 여러 업무를 탭으로 동시에 열고 전환해도 검색조건 · 조회결과 · 스크롤 위치를 그대로 보존
  • 엑셀형 그리드 — 클릭 정렬, 헤더 우클릭(틀고정 · 컬럼조정), 셀 복사 등 엑셀 수준의 그리드 조작 지원
  • 스마트 검색 — 부서 조직트리 · 공통코드 드롭다운 · 달력 · 번호범위 선택으로 코드 암기와 오입력을 원천 차단
  • 내장 도움말 — 각 화면 상단 물음표(?) 팝오버로 별도 매뉴얼 없이 즉시 안내 확인
  • 입력 · 확인 흐름 표준화 — 필수 미입력 항목 강조, 확인 팝업, 동기화 진행률 바로 조작 실수를 사전 예방
